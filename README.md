# 100 Days of Python

A collection of Python projects and exercises completed as part of the 100 Days of Code challenge.

## Projects

- **Day 1**: [Band Name Generator (Python CLI)](./Band%20Name%20Generator%20Day1.py) & [Interactive Web App](./index.html) - Generates iconic band names based on user inputs (city and pet name) with sound synthesizer effects, live canvas visualizer, and custom band styles.
- **Day 2**: [Tip Calculator](./Tip%20Calculator.py) - A bill splitting and tip calculator for calculating individual payments.
